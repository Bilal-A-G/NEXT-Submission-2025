# Ubisoft NEXT Submission 2025

This is my submission for Ubisoft NEXT 2025 in the Technical art category, I'm also happy to announce that I have won 3rd place!

Some of the features of this submission include:

- A volumetric cloud implementation that is faster than Unity's HDRP clouds
- Lots of detailed trees/vegetation that is being rendered at realtime due to LODs, and instancing
- Post processing effects like colour correction and tonemapping for a cinematic feel
- A fully realized, detailed scene, not just a simple diorama

## Running

This repository contains a Unity project, you can clone it or download a zip file and open it with Unity Hub
